We are pleased to announce the release of Hibernate Search 7.2.2.Final.

This release brings a couple bug fixes and dependency upgrades.

+++<!-- more -->+++

== What's new in Hibernate Search 7.2.2.Final

=== Dependency upgrades

[[orm-version]]
Hibernate ORM (link:{hsearch-jira-url-prefix}/HSEARCH-5267[HSEARCH-5267])::
Hibernate Search now depends on Hibernate ORM 6.6.3.Final.
[[elasticsearch-version]]
Elasticsearch (link:{hsearch-jira-url-prefix}/HSEARCH-5276[HSEARCH-5276])::
The Elasticsearch client is now upgraded to 8.15.4

[[other-since-last-7-2]]
=== Other

* link:{hsearch-jira-url-prefix}/HSEARCH-5255[HSEARCH-5255]: Fix possible issue with projection cardinality
when single and multivalued projections are mixed in a single long field path.
* link:{hsearch-jira-url-prefix}/HSEARCH-5268[HSEARCH-5268]: Potential problem with using `@IdClass` in an indexed embedded
object is addressed with the upgrade to Hibernate ORM 6.6.3.Final

And more. For a full list of changes since the previous releases,
please see the link:https://hibernate.atlassian.net/issues/?jql=project={hsearch-jira-project-id}+AND+fixVersion={hsearch-jira-version-id}[release notes].

=== How to get this release

All details are available and up to date on the

== Getting started, migrating

For new applications, refer to the getting started guide:

* link:{hsearch-getting-started-orm-url-prefix}[here for the Hibernate ORM integration]
* link:{hsearch-getting-started-standalone-url-prefix}[here for the Standalone POJO Mapper]

For existing applications, these releases of Hibernate Search are drop-in replacements of their previous micros within the same minors,
assuming you also upgrade the dependencies.
To upgrade to a newer major/minor, see https://hibernate.org/search/documentation/migrate/[migration guides].

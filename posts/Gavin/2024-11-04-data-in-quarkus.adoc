= Jakarta Data in Quarkus
Gavin King
:awestruct-tags: [ "Jakarta Data", "Quarkus", "Hibernate Data Respositories" ]
:awestruct-layout: blog-post
---

We're now seeing a lot of interest in https://in.relation.to/2024/04/01/jakarta-data-1/[Jakarta Data], along with very positive reactions from the people who've already tried it out.

I'm afraid I missed the news that https://in.relation.to/2024/08/08/orm-660/[Hibernate 6.6] is now available in Quarkus, and so I've been slow of the mark in letting everyone know that https://docs.jboss.org/hibernate/orm/6.6/repositories/html_single/Hibernate_Data_Repositories.html[Hibernate Data Repositories], our implementation of Jakarta Data, is now fully integrated with Quarkus. 🎉🎉

To start writing repositories, all you need to add is:

- the Jakarta Data API jar as a dependency, and
- the Hibernate annotation processor.

Here's a https://github.com/gavinking/data-demo-quarkus-mvn[simple example project] to get you started.

You might also be interested in checking out my recent presentation at Devoxx.

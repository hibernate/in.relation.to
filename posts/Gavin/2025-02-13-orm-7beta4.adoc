= Hibernate 7 beta 4 is now available
Gavin King
:awestruct-tags: [ "Hibernate ORM" ]
:awestruct-layout: blog-post
---

The fourth beta release of Hibernate 7 is now https://hibernate.org/orm/releases/7.0/[available].

Along with many bugfixes and minor improvements, this release features the following enhancements:

- The brand-new `Restriction`, `Path`, and `Range` APIs make it easy to add programmatic restrictions to https://docs.jboss.org/hibernate/orm/7.0/introduction/html_single/Hibernate_Introduction.html#restrictions-and-ordering[HQL queries] or Jakarta Data https://docs.jboss.org/hibernate/orm/7.0/repositories/html_single/Hibernate_Data_Repositories.html#dynamic-restrictions[repository methods] in a completely type-safe way.
- The package `org.hibernate.graph` was completely re-engineered, fixing a number of long-standing issues with our implementation of the Jakarta Persistence `EntityGraph` API.
- https://docs.jboss.org/hibernate/orm/7.0/javadocs/org/hibernate/StatelessSession.html[`StatelessSession`] is now able to make use of the second-level cache, reflecting the changing role of this very important API in the Hibernate ecosystem.
- https://docs.jboss.org/hibernate/orm/7.0/repositories/html_single/Hibernate_Data_Repositories.html#reactive-repositories[Reactive repositories] backed by Hibernate Reactive are now a documented feature of https://hibernate.org/repositories/[Hibernate Data Repositories].
- The `hibernate-jfr` module was enhanced to send more events to Java Flight Recorder.
- HQL now provides portable `sha()`, `md5()`, and `hex()` functions.
- https://hibernate.org/orm/processor/[Hibernate Processor] now features much better support for inner classes.

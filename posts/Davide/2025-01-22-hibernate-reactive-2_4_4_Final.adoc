= Hibernate Reactive 2.4.4.Final released
Davide D'Alto
:awestruct-tags: [ "Hibernate Reactive", "Releases" ]
:awestruct-layout: blog-post
---

:getting-started: http://hibernate.org/reactive/documentation/2.4/reference/html_single/#getting-started
:release: https://github.com/hibernate/hibernate-reactive/releases/tag/2.4.4

https://hibernate.org/reactive/releases/2.4/#getting_started[Hibernate Reactive 2.4.4.Final] is now available!

This release is compatible with https://github.com/hibernate/hibernate-orm/releases/tag/6.6.5.Final[Hibernate ORM 6.6.5.Final].

It also contains a couple of bug fixes:

* https://github.com/hibernate/hibernate-reactive/issues/2026[#2026] UnexpectedAccessToTheDatabase error when merging a detached entity with a to-many association
* https://github.com/hibernate/hibernate-reactive/issues/2060[#2060] ClassCastException when using embedded identifiers

{release}[The full list of changes] is available on GitHub.

== How can I get it?

All details are available on the 
link:https://hibernate.org/reactive/releases/2.4/#get-it[Hibernate Reactive website releases page].

If you are new to Hibernate Reactive, {getting-started}[the official documentation] is a good place to start.

= Hibernate Reactive 4.1.0.Final released
Davide D'Alto
:awestruct-tags: [ "Hibernate Reactive", "Releases" ]
:awestruct-layout: blog-post
---

:getting-started: https://hibernate.org/reactive/releases/4.1/#getting_started
:release: https://github.com/hibernate/hibernate-reactive/releases/tag/4.1.0

{getting-started}[Hibernate Reactive 4.1.0.Final] is now available.

Hibernate Reactive 4.1.0.Final is compatible with https://github.com/hibernate/hibernate-orm/releases/tag/7.1.0[Hibernate ORM 7.1.0.Final],
and https://vertx.io/docs/vertx-pg-client/java/[Vert.x SQL client] 5.0.2.

If you need a Hibernate Reactive version compatible with older Hibernate ORM releases or Vert.x releases, you can find
a https://hibernate.org/reactive/releases/[compatibility matrix] on the Hibernate website.

== How can I get it?

All details are available on the 
link:https://hibernate.org/reactive/releases/4.1/#get-it[Hibernate Reactive website releases page].

If you are new to Hibernate Reactive, {getting-started}[the official documentation] is a good place to start.

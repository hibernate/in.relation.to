= Hibernate Reactive 3.0.0.Beta2 released
Davide D'Alto
:awestruct-tags: [ "Hibernate Reactive", "Releases" ]
:awestruct-layout: blog-post
---

:getting-started: http://hibernate.org/reactive/documentation/3.0/reference/html_single/#getting-started
:release: https://github.com/hibernate/hibernate-reactive/releases/tag/3.0.0.Beta2

https://hibernate.org/reactive/releases/3.0/#getting_started[Hibernate Reactive 3.0.0.Beta2] is now available!

This release is compatible with https://github.com/hibernate/hibernate-orm/releases/tag/7.0.0.Beta4[Hibernate ORM 7.0.0.Beta4],
and upgrades the https://vertx.io/docs/vertx-pg-client/java/[Vert.x SQL client] to 4.5.13.

It also contains a couple of bug fixes:

* https://github.com/hibernate/hibernate-reactive/issues/1514[#1514] Need to abort/rollback transactions on error
* https://github.com/hibernate/hibernate-reactive/issues/2079[#2060] ClassCastException when using embeddable ids
* https://github.com/hibernate/hibernate-reactive/issues/2079[#2007] NullPointerException when retrieving @ManyToOne composite table with additional properties in @IdClass

{release}[The full list of changes] is available on GitHub.

== How can I get it?

All details are available on the

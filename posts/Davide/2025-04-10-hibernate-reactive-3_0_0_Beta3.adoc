{getting-started}[Hibernate Reactive 3.0.0.Beta3] and {getting-started24}[Hibernate Reactive 2.4.6.Final] are now available!

Hibernate Reactive 3.0.0.Beta3 is compatible with https://github.com/hibernate/hibernate-orm/releases/tag/7.0.0.Beta5[Hibernate ORM 7.0.0.Beta5],
and upgrades the https://vertx.io/docs/vertx-pg-client/java/[Vert.x SQL client] to 4.5.14.

Here's some of the most interesting changes in the release:

* https://github.com/hibernate/hibernate-reactive/issues/2139[#2139] Add batching methods for upsert to the StatelessSession
* https://github.com/hibernate/hibernate-reactive/issues/2055[#2055] Bug fix: Setting `hibernate.query.mutation_strategy.global_temporary.create_tables` to false had no effect
* https://github.com/hibernate/hibernate-reactive/issues/2026[#2026] Bug fix: Exception when merging a detached entity with a ToMany association

Hibernate Reactive 2.4.6.Final includes the same bug fixes, upgrades to https://github.com/hibernate/hibernate-orm/releases/tag/6.6.13[Hibernate ORM 6.6.13.Final],
and the https://vertx.io/docs/vertx-pg-client/java/[Vert.x SQL client] to 4.5.14. 

The fulll list of changes for {release}[Hibernate Reactive 3.0.0.Beta3] and {release24}[Hibernate Reactive 2.4.6.Final] is available on GitHub.
